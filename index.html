数据与隐私

本地保存

记录不会上传，也没有账号或第三方跟踪。数据属于当前设备、浏览器与网页地址；清理网站数据、无痕浏览、换地址或移除应用可能使记录消失。

备份为明文，可能包含敏感内容。请保存到你控制的位置；放入云盘或分享给他人会离开本工具的隐私范围。

使用说明

怎么记录

“一键记一次”会立即新增今天 1 次，其他字段保持未填写。点记录的“编辑”补充信息；“详细记录”可以补记以前的日期，或填 0 次只记录健康习惯。时长是本条合计，视频时长包含在实际浏览合计内。

iPhone 本地 HTML 的限制

在“文件”、邮件或聊天中点开 HTML，通常进入预览，不能据此确认脚本或保存可用。iPhone Safari 不能像电脑浏览器一样把任意本地 file:// 文件当作稳定网页应用打开。即使某个查看器能运行脚本，本地文件存储也可能受限；换文件名或路径可能得到另一份数据。

在 Safari 中可靠使用

把此 HTML 或随附 PWA 静态文件放在你控制的网址，用 Safari 访问。PWA 需要 HTTPS（本机 localhost 是开发例外；手机访问电脑的局域网 HTTP 地址不属于此例外）。首次打开需要获取静态文件，记录不发送到服务器。网页添加主屏幕后，在主屏幕入口检查“离线资源已就绪”，再测试飞行模式。

Safari → 分享 → 添加到主屏幕；如有“作为网页 App 打开”，开启它。菜单可能随系统版本不同。请尽量固定一个入口使用，Safari 与主屏幕应用可能使用不同存储；迁移请用 JSON 导出再导入。

备份与导入

JSON 适合完整备份，CSV 适合查看表格，两者都能导入。导入先预览再确认，错误文件不会改变现有记录。CSV 的空白表示未填写；true / false 表示是 / 否。备份没有加密，请自行保护。导出后建议用导入预览检查文件能被读取，再取消预览。

隐私与保存

单文件无网络请求、外部字体或跟踪。PWA 只加载自身静态资源。localStorage 不是加密保险箱；本工具无法识别无痕模式，也不能保证浏览器永远保留数据。留意页面的保存状态，定期导出。申请持久保存仅是向浏览器提出请求，不能防止手动清除。

关于舒适

留意舒适、睡眠和生活安排，无需用次数判断自己。温和方式和合适润滑有助减少摩擦；出现疼痛或麻木先停止刺激、休息，持续或反复不适可咨询医生。本工具不进行诊断。
